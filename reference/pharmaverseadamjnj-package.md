# pharmaverseadamjnj: J&J Innovative Medicine ADaM Test Data

A set of Analysis Data Model (ADaM) datasets constructed by modifying
the ADaM datasets in the 'pharmaverseadam' package to meet J&J
Innovative Medicine's standard data structure for Clinical and
Statistical Programming.
